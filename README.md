# TrafficTown2D

TrafficTown2D is a 2D traffic simulation game developed using Unity. 
The project simulates vehicles moving through roads and traffic signals.

## Requirements

### Software Requirements

- Unity Hub
- Unity 6 or compatible Unity version
- Visual Studio Code / Visual Studio
- Git
- GitHub account

### Hardware Requirements

- Processor: Intel Core i3 or equivalent
- RAM: Minimum 4 GB
- Storage: Minimum 2 GB free space
- Display: 1280 × 720 or higher
- Keyboard and mouse

### Unity Packages

The project uses the following Unity packages:

- Universal Render Pipeline (URP)
- 2D Renderer
- Input System
- Unity UI
- TextMeshPro
